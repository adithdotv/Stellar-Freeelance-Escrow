# Screenshots

Submission screenshots live here. Three are required:

| File | What it shows | How to capture |
|---|---|---|
| `mobile.png` | The app on a phone-width viewport | Open the live app, use the browser device toolbar (e.g. iPhone 12), show the job list and a job card stacked in one column |
| `ci.png` | Both CI workflows passing | The repo's **Actions** tab with the Contracts and Frontend runs green |
| `tests.png` | Tests passing | Terminal output of `cd app && npm test` (25 pass) or `cd contracts && cargo test` (31 pass) |

Once added, reference them from the top-level [`README.md`](../../README.md).
